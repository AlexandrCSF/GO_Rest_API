# Golang REST API Сервис для отображения заказов

Этот проект представляет собой REST API сервис для работы с заказами, интегрированный с Apache Kafka и PostgreSQL.

## Основные возможности

- REST API для работы с заказами
- Интеграция с Apache Kafka для обработки сообщений
- Кеширование данных с автоматической инвалидацией
- Graceful shutdown приложения
- Логирование всех операций
- Docker контейнеризация

## Архитектура

Сервис состоит из следующих компонентов:

1. **REST API** - HTTP сервер для обработки запросов
2. **Kafka Consumer** - получает заказы из Kafka и сохраняет в БД
3. **Cache** - кеширует заказы с автоматической очисткой устаревших данных
4. **PostgreSQL** - база данных для хранения заказов

## API Endpoints

- `GET /order?uid={orderUID}` - получение заказа по ID
- `GET /orders` - получение всех заказов
- `POST /order` - создание нового заказа

## Технологии
- **Go 1.25** - основной язык программирования
- **PostgreSQL** - база данных
- **Apache Kafka** - брокер сообщений
- **Docker** - контейнеризация
- **Gorilla Mux** - HTTP роутер
- **Logrus** - логирование
